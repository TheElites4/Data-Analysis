# The Cost of Financial Intermediation in South Africa and Agricultural Market Integration Across Sub-Saharan Africa

NDTA631 - Data Analysis and Visualisation | Group Assignment 2026 | Sol Plaatje University

## Overview

This repository contains a complete data analysis and visualisation pipeline built on two
World Bank Data360 datasets:

1. **Interest Margin to Gross Income (Core FSI)** - IMF Financial Soundness Indicators for
   South Africa's deposit-taking banks, annual, 2008-2024.
2. **AgriLink / AgriConnect Household Indicators** - smallholder agricultural market-access
   indicators across 34 Sub-Saharan African countries. *South Africa is not part of this
   survey programme*, so it is used deliberately as regional benchmarking context
